## Authentication

| Method | Header | Who uses it |
| --- | --- | --- |
| Staff session | `Authorization: Bearer <token>` | People. Issued by `POST /api/auth/verify` after a password **and** an emailed one-time code. |
| API key | `x-api-key: <key>` | Machines. Scoped per key. |

### Scopes

Least to most privileged: **`webhook`** < **`automation`** < **`staff`** < **`admin`**. A scope opens everything below it.

| Scope | What it is for |
| --- | --- |
| `webhook` | Webhook key. The narrowest scope — usage, lead and conversation ingestion only. |
| `automation` | Automation key or any staff session. Clients, invoices, packages, agents. |
| `staff` | Staff session, or an admin key. Day-to-day CRM work. |
| `admin` | Admin only. Financials, settings, procurement, archive, exports. |

The **admin key opens everything** and exists as break-glass for when email delivery fails or the last admin loses their second factor. Set `ALLOW_API_KEY_LOGIN=false` once staff accounts exist.

> **Automation writes through this API, never to the database.** Tenancy, quota and the tax rules live in these routes. A direct Postgres write bypasses all three.

## Errors

Every failure is JSON with an `error` field carrying a sentence meant for a person:

```json
{ "error": "Your session has expired. Please sign in again." }
```

| Status | Meaning |
| --- | --- |
| `400` | The request was understood and is wrong — the message says how. |
| `401` | Not signed in, or the key is invalid or revoked. |
| `403` | Authenticated, but not to this scope. |
| `404` | No such record — or it belongs to another tenant. |
| `409` | Refused because of state: an accepted quote, a duplicate upload. |
| `413` | Upload too large (documents cap at 10 MB). |

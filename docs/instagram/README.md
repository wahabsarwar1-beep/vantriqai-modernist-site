# VantriqAI Instagram launch kit

Everything needed to open the Instagram account and link it to the Facebook
Page (https://www.facebook.com/profile.php?id=61594465987920).

## 1. Create the account (about 5 minutes, on your phone)

1. Install Instagram and choose **Create new account**. Use a business email,
   for example hello@vantriqai.com, not a personal one.
2. **Username:** `vantriqai`. If it's taken, try `vantriq.ai`, `vantriqai.official`
   or `vantriqai_hq`, in that order.
3. **Name field:** `VantriqAI | AI agents for WhatsApp & Instagram`. The name
   field is searchable, so the keywords help people find you.
4. **Profile picture:** `profile-picture.png`. It's built to survive the
   circle crop.
5. Go to **Settings → Account type and tools → Switch to professional account → Business**.
   Set the category to **Software Company** (or *Information Technology Company*).
6. Link it to Facebook: **Settings → Accounts Center → Add accounts →** add
   the Facebook account that manages the Page. Then in the Facebook Page, go to
   **Settings → Linked accounts → Instagram → Connect**. This connection also
   lets VantriqAI's own Instagram DM agent run on this account later.
7. Contact options: email, and WhatsApp **+92 341 1120049** (Edit profile →
   Contact options → WhatsApp).
